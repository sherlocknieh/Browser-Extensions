# 二维码 - 浏览器插件

极简主义+全功能+全平台的二维码插件;

## 功能完备:

**1. 二维码生成:**

  - 当前页面地址二维码: 点击插件工具栏图标
  - 选中文本生成二维码: 在选中文本上右键
  - 网页链接生成二维码: 在网页链接上右键

**2. 二维码识别:**

  - 网页图片二维码识别: 在图片上点击右键
  - 本地文件二维码识别: 点击插件工具栏图标
  - 剪贴板图片二维码识别: 工具栏图标右键菜单

## 极简设计: 

  - 使用最简洁的外观设计, 不添加任何多余元素;
  - 使用最符合直觉的入口设计, 需要时触手可及;

支持 Chrome、Edge、Firefox 浏览器;
