# 二维码 - 浏览器插件

## 功能:

**1. 二维码生成:**

   - 当前页面地址二维码: 点击插件工具栏图标
   - 选中文本生成二维码: 在选中文本上右键
   - 网页链接生成二维码: 在网页链接上右键

**2. 二维码识别:**

   - 网页图片二维码识别: 在图片上点击右键
   - 本地文件二维码识别: 点击插件工具栏图标
   - 剪贴板图片二维码识别: 工具栏图标右键菜单
   - 一维条形码识别: 二维码识别失败后自动兜底 (Code128/Code39/Code93/EAN/UPC/ITF)

- 二维码识别: jsQR
- 二维码识别增强: zxing-js (透视变形二维码, 条形码识别)
