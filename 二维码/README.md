# 二维码插件

生成二维码:

- 为当前网页生成二维码
- 为选中的文本生成二维码
- 为网页中的链接生成二维码

识别二维码:

- 识别网页图片中的二维码
- 粘贴图片/本地上传图片识别二维码

## 用到的库

- 跨浏览器开发: wxt, vue3
- 二维码识别: jsqr
- 二维码生成: qrcode-generator
- 网页截图: js-web-screen-shot
- 弹窗提示: sweetalert2
