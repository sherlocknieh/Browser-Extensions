# 二维码插件

生成二维码:

- 为当前网页生成二维码
- 为选中的文本生成二维码
- 为网页中的链接生成二维码

识别二维码:

- 识别网页图片中的二维码
- 粘贴图片/本地上传图片识别二维码

## Done

- [x] 支持彩色二维码, 圆点二维码, SVG 图片二维码
